## 提出前チェック

提出CSVが完成したら、公式のサンプルCSVを基準に `uv run python -m tools.validate_submission` を実行する。ID列が `id` でない場合は `--id-column`、IDが存在しない場合は `--no-id` を指定する。数値列は `--numeric` で明示的に検証する。

このツールは**オフラインの形式・整合性チェックのみ**であり、予測値の許容範囲や確率総和、提出回数・コンペ規約、Notebook提出条件を検証しない。Kaggleへの自動アップロード・提出も行わない。
